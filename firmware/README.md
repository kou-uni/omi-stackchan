# ファームへの追加分

上流 [BasedHardware/omi](https://github.com/BasedHardware/omi)（MIT）の tag `Omi_CV1_v3.0.15` に対する差分。
作業ツリーは `~/omi-upstream`（ブランチ `omi-time`）。

## 0001-storage-timestamps.patch — 貯める音声に時刻を入れる

**なぜ:** 純正は本体に貯める音声に時刻を一切付けない。中断の印も無い。
これだとライフログとして「いつの話か」が分からない。

**やったこと（1ファイル・約130行）:**

- BLE の受け口を追加（`19b10030` / `19b10031`）。Mac が現在時刻を書き込む。読むと端末の現在時刻と起動IDが返る
- 端末に時計はないので、**渡された時刻＋起動からの経過時間**で現在時刻を作る。電源を切ると失われるので、繋いだら入れ直す
- 貯める音声の列に、**1分ごと**と**時刻を渡した直後**に「時刻の印」を混ぜる
- 起動ごとに変わる**起動ID**を印に入れる → 後から**電源の入れ直し**を見分けられる

**保存の形:** 440バイトのページに `[長さ][中身]` を詰める（純正と同じ）。
長さ `0xFF` が時刻の印、長さ `0` は「このページはここまで」。音声のかたまりは最大160バイトなので、印と衝突しない。

**大きさ:** 純正に対して **容量 +564 バイト / RAM +136 バイト**（純正 RAM 99.24% → 99.27%）。

**まだ実機には書き込んでいない。** ビルドが通るところまで。

## 使う道具（Mac 側）

- `tools/set_time.py` — 時刻を渡す・読む
- `tools/timeline.py` — 吸い出したファイルから印だけを拾って区切りを表示（**音声の中身は読まない**）
