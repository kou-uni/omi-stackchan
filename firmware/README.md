# ファームへの追加分

上流 [BasedHardware/omi](https://github.com/BasedHardware/omi)（MIT）の tag `Omi_CV1_v3.0.15` に対する差分。
作業ツリーは `~/omi-upstream`（ブランチ `omi-time`）。

## 0001-storage-timestamps.patch — 貯める音声に時刻を入れる

**なぜ:** 純正は本体に貯める音声に時刻を一切付けない。中断の印も無い。
これだとライフログとして「いつの話か」が分からない。

**やったこと（1ファイル・約130行）:**

- BLE の受け口を追加（`19b10030` / `19b10031`）。Mac が現在時刻を書き込む。読むと端末の現在時刻と起動IDが返る
- 端末に時計はないので、**渡された時刻＋起動からの経過時間**で現在時刻を作る。電源を切ると失われるので、繋いだら入れ直す
- 貯める音声の列に、**1分ごと**と**時刻を渡した直後**に「時刻の印」を混ぜる
- 起動ごとに変わる**起動ID**を印に入れる → 後から**電源の入れ直し**を見分けられる

**保存の形:** 440バイトのページに `[長さ][中身]` を詰める（純正と同じ）。
長さ `0xFF` が時刻の印、長さ `0` は「このページはここまで」。音声のかたまりは最大160バイトなので、印と衝突しない。

**大きさ:** 純正に対して **容量 +564 バイト / RAM +136 バイト**（純正 RAM 99.24% → 99.27%）。

**まだ実機には書き込んでいない。** ビルドが通るところまで。

## 0002-disable-wifi.patch — Wi-Fi 一式を切る

**なぜ:** **スマホと Omi は常に体の近くにある**ので、届く範囲は Bluetooth で足りる。
Wi-Fi は「離れた場所へ速く送る」ための仕組みで、この使い方では出番がない。
外から触れる面も減る。

**効果（実測）:**

| 構成 | 容量 | RAM | 更新パッケージ |
|---|---|---|---|
| 純正 | 792,548 | 447,156（**99.24%**） | 970KB |
| 純正＋時計 | 793,112 | 447,292（99.27%） | 970KB |
| **純正＋時計－Wi-Fi** | **229,588** | **365,960（81.22%）** | **407KB** |

**RAM の空きが 3KB → 84KB。** 今後の機能追加（押し始めの通知、鍵かけ、満杯の通知）が安全にできる余裕ができた。
無線での書き込みも速くなる。

**戻し方:** `omi.conf` のコメントアウトを外し、`sysbuild.conf` の `SB_CONFIG_WIFI_NRF70` を `y` に。

## 0003-explicit-recording.patch — 勝手に録音しない

**なぜ:** 純正は電源が入っている限り録り続け、**使う側に止める手段がない**。
電池も減るし、意図しない音まで残る。

**やったこと:**

- **起動直後は止まっている。** 明示的に始めたときだけ録る
- 受け口 `19b10032` に 1 を書くと開始、0 で停止。読むといまの状態が分かる
- **開始時に短く1回、停止時に長く1回、本体が震える**（体で分かる）
- 開始時に**必ず時刻の印を残す**
- 電源を切ると必ず「止まっている」に戻る（安全側）

**実機で確認（2026-09-21）:** 3分放置して 0 バイトのまま。開始すると録れる。

## 実機への書き込み（2026-09-21 成功）

**いま実機で動いているのは自前ファーム（版 0.0.1 / Wi-Fi なし）。**

### ハマりどころ：版数を上げないと切り替わらない

ブートローダーは **版数が上のものしか受け付けない**（`CONFIG_MCUBOOT_DOWNGRADE_PREVENTION=y`）。
同じ版数だと、送信は成功するのに**黙って無視され、前のまま起動する**。

- 焼くたびに `omi.conf` の `CONFIG_MCUBOOT_IMGTOOL_SIGN_VERSION` を上げる
- 送るだけでは切り替わらない。**「次の起動で使う」印をつけて再起動**まで必要
- 手順は `tools/flash.sh` にまとめた

### 戻し用を用意してある

版数を上げた結果、**純正の配布ファーム（版 0.0.0）はそのままでは戻せない**。
そこで **中身は純正のまま、版数だけ 0.9.0 に上げたもの**をビルドして保管した。

- 置き場: `~/omi-firmware-backup/restore-0.9.0/`（リポジトリには入れない）
- 純正ソース（tag `Omi_CV1_v3.0.15`）から、版数の指定を1行足しただけ
- いつでも `tools/flash.sh` で戻せる

- `tools/set_time.py` — 時刻を渡す・読む
- `tools/timeline.py` — 吸い出したファイルから印だけを拾って区切りを表示（**音声の中身は読まない**）
- `tools/flash.sh` — 無線で書き込む（送る→印をつける→再起動→確認）
