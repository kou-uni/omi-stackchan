## 首にかけた録音機は、今日は何もしません

今日、僕の首には録音機がかかっています。**Omi** という、手のひらに乗る小さな機械です。
でも、今日はこれで何も見せません。**理由も含めて、持ち帰ってもらえたらと思います。**

### この道具は「1日」でできている

朝つけて、夜はずします。その間の声を、本体の中に貯めます。
帰ったら家の Mac に吸い出して、文字起こしをして、要約します。

そして夜、**机の上のロボットが、その日について問いを1つだけ投げてきます。**

> 「測り方を変えたら結果が変わったけど、最初の測り方はどこで間違えたんだろう？」

まとめを読み上げられても、人は聞き流します。**問われると、答えようとして考える。**
その日の記録が値打ちを持つのは、たぶんそこです。

翌朝、話しかけると今日やることを返してきます。昨夜の自分との約束が、いちばん上に来ます。

### なぜ今日、これを見せないのか

**この道具の良さは「時間の流れ」にあって、5分では見せられないからです。**

ロボットは、その場で動いて笑うから刺さります。目の前で起きることに、説明は要りません。
録音機は違います。**1日貯めて、夜に返ってくる**。今この場で見せられるのは、
首にかかった小さな機械そのものだけです。

デモにならないものを、無理にデモにすると、**どちらも薄くなります。**
だから今日は、着けているだけです。

### 外に出さないために、何をしているか

今日のロボットの話と、根っこは同じです。

| | |
|---|---|
| 文字起こし | **この Mac の中**（Whisper） |
| 要約 | **この Mac の中**（ローカルの LLM） |
| 人の名前 | **記号に置き換える**（「Aさん」）。対応表は外に出さない |
| 外に出るもの | **「今日やること」の短い文だけ**。Slack に届く |
| 出さないもの | 音声、文字起こし、要約そのもの |

外に出る一歩手前に「関所」を置いてあります。
鍵やパスワードらしき文字列、消し忘れた人名、外に出したくない技術的な情報を、
**機械が二重に見て、最後は自分の目で確認してから**通します。

### 正直に言っておくこと

- **この録音機は、僕の声だけを録る仕組みを持っていません。** 周りの声も入ります
- 今日、嫌だと思われた方は、その場で言ってください。**目の前で電源を切ります**
- 録れてしまった分は、**持ち帰ってから、その時間帯を消します**（その場では消せません）

**黙って録らない。** それだけは守ります。
今日ロボットの話でお伝えしている「同意の導線がない」という問題は、
僕自身にも同じように当てはまるからです。
