# 実機で確かめること（やるリスト）

本人が実機のそばにいるときにやる確認。**外出中はできないもの**をここに集める。

---

## 1. マイクの感度を上げる　★次にやる

- **いまの状態**: 録音の音量が小さい（平均 -46dB、最大 -20dB）。設定値は **6**（受け口 `19b10012`）
- **やること**: 値を上げて録音し、音量がどう変わるか測る。上げすぎると割れるので、段階的に
- **なぜ**: 文字起こしの精度に効く。下の「無音を録らない」も、音量が小さいことが原因かもしれない
- **確認方法**: 同じ距離・同じ声で録って、音量（dB）と文字起こし結果を比べる

## 2. 無音を録らない（DTX）の再挑戦

- **やったこと**: Opus の DTX を有効にしたら、**2分間の録音が 743,600 → 17,600 バイト（42分の1）** になった
- **問題**: 45秒間、はっきり話したつもりでも**全フレームが無音扱い**になった（※本人が実際に声を出したかは未確認）
- **判断**: 危険なので**いったん戻した**（0.0.9）。声を落とす可能性がある設定は残さない
- **再挑戦の条件**:
  1. まずマイク感度を上げる（上記1）
  2. **声を出したことを確認できる状態**で測る
  3. 無音と声のフレームが**混ざる**ことを確認する（全部無音 = 失敗）
- **代案**: Opus 任せにせず、**自前で音量を見て判定する**（しきい値を Mac から調整できるようにする）

## 3. 丸1日の取得テスト

- 朝 `record.py on` → 夜 `record.py off` → 吸い出し
- 見るもの: 取れた時間 / すき間 / 時刻の印 / 電池の減り / 容量
- **本体に貯められるのは約33時間分**（実測: 1時間あたり約14.4MB、上限480MB）
