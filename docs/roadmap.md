## やりたいこと

**誰のため：** 自分（kou）。1日じゅう喋って、考えて、約束して、そのまま忘れていく人。

| | 場面 | スタックチャンが何をするか |
|---|---|---|
| **E（最初にやる）** | イベント当日 | Omi で録った自分のライフログを Mac のローカル LLM が要約し、**人前でスタックチャンが自分にアドバイスする** |
| A（あとで） | 帰宅したとき | 会話の中の**約束だけ**を拾って、首を向けて伝えてくる。リマインダーにも入れる |
| B（あとで） | 夜の振り返り | 1日のまとめから、**問いを1つだけ**声で投げてくる |

**E で見せたいこと：**
スタックチャン側の口上は「この部屋の声は、この部屋から出ていません」。
Omi がそれを**1日ぶんに拡張**する。**「僕の1日の声は、このMacから一歩も出ていない」**。

## マイルストーン

### M0　ライブ音声をローカルで閉じる　✅ 2026-09-19

- **DoD:** Omi → BLE → Mac → Whisper で文字になる。クラウドを通らない ← **達成**

### M1　接続が切れない／切れても戻る　★いまのボトルネック

1日取るには、**ライブでも吸い出しでも**、長時間の接続が要る。吸い出しは1日分で数十分かかる見込み。

- [ ] 切断の原因を特定する（距離？ Omi 側の省電力？ macOS 側？）→ `conn_probe.py` を距離・時間を変えて回す
- [ ] 切れたら**自動で繋ぎ直す**（`conn_probe.py` に骨組みあり）
- [ ] **取りこぼし率**を測る（実測41/秒 vs 理論50/秒の差は何か。ヘッダの連番で欠けを数える）
- **DoD:** 1時間ライブで受けて、切断→自動復帰が記録され、取りこぼし率が数字で出る

### M2　本体に貯めた音声を吸い出す（壊さずに）

- [x] 本体の音声を吸い出して空にできた（2026-09-19）
- [ ] 速くする（いまは約24KB/秒）
- [ ] **読むだけ**で吸い出す。消去系コマンドは送らない
- [ ] 吸い出したフレームを Opus decode → WAV
- [ ] **時刻が付くか**を確認（RTC。付かないならいつの音声か分からない）
- **DoD:** 30分外で録って、帰宅後に Mac で30分ぶんの WAV になる。本体の音声はまだ消えていない

### M3　ユースケースごとに取れるか（検証マトリクス）

「取れた」は1回では言えない。**使う場面ごとに**確かめる。下の表を埋める。

| # | 場面 | 確かめること |
|---|---|---|
| 1 | Mac の横で1時間 | 切れないか・取りこぼし率 |
| 2 | 距離 1m / 3m / 5m / 別の部屋 | どこから切れるか（RSSI と対応づける） |
| 3 | **圏外に出て戻る** | 切断中は本体に貯まるか。戻ったとき**すき間**は何秒か |
| 4 | **電源オン・オフを複数回** | 区間が分かれて残るか。それぞれに時刻が付くか。前の分が消えないか |
| 5 | 首から下げる / ポケット / 服の下 | 音量・文字起こしの読める率 |
| 6 | 歩行・電車・カフェ | 騒音下で読めるか |
| 7 | 会議・雑談（複数人） | 自分の声と他人の声が分けられるか |
| 8 | 充電中 | 録れるか |
| 9 | **丸1日** | 電池が持つか。容量が溢れたら古いものが上書きされるか |
| 10 | iPhone の Omi アプリが近くにある | 接続を奪われないか（**解除しておく前提の確認**） |
| 11 | MacBook がスリープ・蓋閉じ | 吸い出しが止まるか |

各行で記録する：**実時間 / 取れた秒数 / すき間 / 時刻の有無 / 読める率 / 電池**

### M4　1日パイプライン

- **DoD:** 帰宅後コマンド1つで、その日の文字起こしが時刻つきで揃う

- **DoD:** その日のテキストから、30秒で話せるアドバイスが出る
