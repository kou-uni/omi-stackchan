# ロードマップ

**目指すもの：毎日を一緒に走ってくれるエージェントのエコシステム。**

自分の1日をクラウドを通さずに記録し、安全な場所に詳細を残し、そこから
「エージェントが学ぶべき知見」だけを Obsidian に構造化して蓄える。
夜はスタックチャンが今日の学びを問いかけ、明日の備忘をくれる。
朝に問えば今日やることを返し、Hermes 経由で Slack に届く。

- 起点: 2026-09-19 / 作業機: Mac Studio・MacBook
- 近い予定: **2026-09-29（火）Crypto Cafe and Bar**（stackchan-lab 側が主役。こちらは任意）

---

## 全体の流れ（7段）

```
① 記録        Omi が1日を録る（クラウドを通さない）
       ↓
② 保管        安全領域に貯める（暗号化・ネット遮断・学習に使わせない）
       ↓
③ 詳細要約    手元の LLM で「今日の詳細」を作る（安全領域の中で完結）
       ↓
④ 蒸留        学ぶべき知見だけを抜き出し、Obsidian に構造化して保存
       ↓
⑤ 夜の対話    スタックチャンが今日の学びを問いかけ、明日の備忘を渡す
       ↓
⑥ 朝の対話    問いかけると、今日やることを返す
       ↓
⑦ 連携        Hermes 経由で Slack に通知（出口にもゲートを置く）
```

**価値が出始めるのは④から。** ①〜③はそこへ至る土台。

3. **④をつなぐ** ← ここで初めて日々の価値が出る

|---|---|
| 丸1日、取り切れるか（電池・容量・装着） | 実機で1日テスト |

| iPhone を受け手にできるか（常時接続・バックグラウンド） | 小さいアプリを書いて試す |
| 「学ぶべき知見」をどう選ぶか | ④の基準づくり |
