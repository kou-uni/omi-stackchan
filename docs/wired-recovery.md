# 有線での書き込み・復旧（調査結果・いまは保留）

2026-09-21 調査。**当面は無線で進める。** 必要になったらここから始める。

---

## 分かったこと

### 1. 充電面の接点から、分解せずに繋がる

Omi 本体の充電面には、**中心の点・同心円のリング2本・小さな点4つ**がある。
純正の充電器はこのうち**2箇所（中心と内側リング＝電源と GND）しか使っていない**。

公開されている回路図（Seeed Studio 製）の6ピンコネクタ `J1`:

| ピン | 中身 |
|---|---|
| 1 | 電源 |
| **2** | **リセット** |
| 3 | シリアル送信（ログ） |
| **4** | **SWDCLK** |
| 5 | シリアル受信 |
| **6** | **SWDIO** |
| 外周 | GND |

### 2. メーカー公式が、そのための商品を出している

**Omi Firmware Developer Kit** — https://www.omi.me/products/omi-firmware-developer-kit

- $59.99（定価 $99.99）。**日本への送料が約8,000円** → 合計 17,000円超（関税別）
- 中身: SEGGER J-Link / USB ケーブル / **Omi 専用の接続基板（Flash PCB）** / 2ピンのジャンパー線
- 公式の説明: **「分解せずに nRF5340 のデバッグ端子にアクセスできる」**
- → **充電面の接点から繋がる**という読みの裏付けになっている
- 公式は「ロックされたブートローダーも、独自ツールチェーンも、許可も不要」と明言

### 3. 文鎮化しても復旧の道がある

2つの核をそれぞれ初期化して書き戻す手順が公開されている
（`nrfjprog --recover -f nrf53 --coprocessor CP_NETWORK` / `CP_APPLICATION`）。
書き戻す中身（両方の核のファーム一式）は GitHub のリリースにある。
純正の配布物は手元の `~/omi-firmware-backup/` にも保存済み。

## 有線が要るのはどういうときか

- 改修版が起動せず、無線でも応答しなくなったとき
- ブートローダーそのものを入れ替えたくなったとき（自動で戻る仕組みを入れる等）
- 起動直後の挙動を追いたいとき（無線が立ち上がる前のログ）
